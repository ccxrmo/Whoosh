# Whoosh's Planned Features and Released Features

## File information for repository owners and contributors
### Usage
Use this file to add features that it's sure that are going to be added or that they're planned for a future update. We use this file to take track of what could be the next major updates for Whoosh's app.
> [!IMPORTANT]
> This is only for the Whoosh app and not for the Whoosh Twitter Patch. We're not going to add more features to the Twitter app besides reviving it. If you're interested of trying out these features that are available for Whoosh but still want to use Twitter, make sure to check out Whoosh for Desktop and Whoosh Web.

Make sure to check out the **rules** for contributing on Whoosh in the Github's main page.

## Planned Features
### How the list works
If a feature has its checkbox checked it means that feature is being implemented / has been implemented on Whoosh.  
If a feature has its checkbox not checked it means is considered but not added yet.  
If a feature is marked by a line it means that it's scrapped in its entirety or partially.  
If a feature is instead highlighted it means that it has a higher priority than other features.  
> [!NOTE]
> Most of the items listed are both hypothetical and still pre-development stage. Might get unrealistic over time. This list just gives an idea of what **Whoosh** could be.

- <mark>Customizable Profiles</mark>
    - [ ] Custom colors selectable with a color wheel.
    - [ ] Add **widgets** to your profile! → **Suggested to see: Third-Party Connections**
    - [ ] Banners
    - [ ] Badges
    - [ ] Custom Fonts
          
- <mark>UI and App Base</mark>
    - [ ] A **Home Page** where general stuff is displayed
    - [ ] A **Spotlight** of the most viewed posts in the current moment
    - [ ] An **Explore Page** divided in categories such as Music, Film, Books and so on.
    - [ ] Profile and Settings
        - [ ] Customize your profile options
        - [ ] Profile displays widgets on a separate tab from posts.
              
 - Third-Party Connections
    - [ ] Music Services: Spotify, Apple Music, Youtube Music, Amazon Music *(and so on...)*
    - [ ] Last.fm *(aka display your most streamed artists and albums)*
    - [ ] Letterboxd and AOTY *(displays reviews on profile about albums and films)*
    - [ ] Kindle (support unknown, this would've been useful to show details about the books you're reading)
    - [ ] Steam (shows games you've been playing)
